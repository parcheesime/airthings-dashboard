# AirThings Data Dashboard

An indoor air quality monitoring dashboard and data pipeline built with the AirThings API, Python, and interactive visualizations.

## Project Goals

- Connect to the AirThings API
- Pull and store historical sensor data
- Track indoor air quality trends over time
- Visualize PM, VOC, CO2, humidity, and temperature data
- Detect and analyze spike events
- Compare environmental readings with logged observations

## Planned Features

- API authentication and automated data pulls
- Local data storage and CSV exports
- Time-series visualizations
- Interactive dashboard
- Event logging and annotation
- Historical trend analysis
- Automated scheduled updates

## Tech Stack

- Python
- Pandas
- Requests
- Streamlit
- AirThings API
- Git/GitHub
